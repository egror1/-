## Сборка и проверки

```sh
cmake -S . -B build
cmake --build build
./build/cycles
cmake --build build --target clang-format
clang-tidy main.cpp -- -std=c++20
python3 tests/test_cycles.py ./build/cycles
cmake -S . -B build-debug -DENABLE_DEBUG=ON
cmake --build build-debug
```

Требуются GCC/Clang с C++20, CMake ≥ 3.20, clang-format и clang-tidy ≥ 18, Python 3.
Строгие флаги: -Wall -Wextra -Werror -Wpedantic. Каталоги build и build-debug игнорируются Git.

## Четыре задания

1. Сумма чисел от 1 до n, кратных 5 и не кратных m. Ввод: 2 ≤ n ≤ 1000000, 1 ≤ m < n. Аккумулятор long long исключает переполнение в этих пределах.
2. При a ≥ 0: (2²·4²·6²·8²) − a = 147456 − a. При a < 0: (3−2)(6−2)(9−2) = 28. Вычитание a выполняется после произведения.
3. Таблица x, Y(x), S(x), N на [0,1] с шагом 0.2. Y(x) = (1−x²/2)cos(x) − (x/2)sin(x). Член A_n = (−1)^n (2n²+1)x^(2n)/(2n)!. Используется рекуррентное отношение, без степеней и факториалов. Последний включённый член имеет модуль < 1e−6; N — его индекс (первый член A_0 = 1). На данном отрезке знакопеременные члены убывают, поэтому остаток по модулю меньше 1e−6.
4. y_0 = 0; y_i = sqrt(2i + y_(i−1)), i = 1..n. Это даёт sqrt(2n + sqrt(2(n−1) + ... + sqrt(2))). Выводятся приближения на итерациях 3, 5, 10, если они достигнуты, и итоговое значение. Для нового n можно выбрать y и снова пункт 4.

Вещественные входы должны быть конечными, |a| ≤ 1e100. Число итераций для задания 4: 1..1000000. Пределы указаны в приглашениях. Недопустимые данные и хвост строки отклоняются; после ошибки можно продолжить. EOF завершает работу.

## Проверки

115 автоматических проверок: прямые суммы, обе ветви произведения, все 6 строк таблицы с независимой суммой через факториалы, промежуточные корни, ошибочный ввод, повторное выполнение и EOF.
