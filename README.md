# Лабораторная работа 1 Часы

Программа принимает два целых числа в одной строке — часы от 0 до 23 и минуты от 0 до 59. Результат содержит время в 12-часовом представлении, согласованные окончания и часть суток. В 00:00 выводится «полночь», в 12:00 — «полдень», при остальных целых часах — слово «ровно» вместо количества минут.

Для 00:01–00:59 используется 12-часовое обозначение «12 часов … ночи». Интервалы частей суток: ночь [00:00; 05:00), утро [05:00; 12:00), день [12:00; 18:00), вечер [18:00; 24:00). Полдень и полночь обрабатываются раньше этих правил.

## Сборка и проверка

```sh
g++ -std=c++20 -Wall -Wextra -Wpedantic -Werror main.cpp -o clock
printf '13 12\n' | ./clock
python3 tests/test_clock.py ./clock.out
```

Проверка охватывает все 1440 допустимых сочетаний часов и минут, 6 ошибок диапазона, 9 ошибок синтаксиса и 3 допустимых варианта форматирования ввода: всего 1458 запусков. Скрипт сравнивает полный вывод и код завершения. Неверный ввод включает дроби, текст, неполный ввод, лишние значения и целое число за пределами диапазона int. Скрипт не требует сторонних Python-пакетов.

## Примеры

| Ввод | Результат |
|---|---|
| 2 48 | 2 часа 48 минут ночи |
| 5 00 | 5 часов утра ровно |
| 12 00 | полдень |
| 12 23 | 12 часов 23 минуты дня |
| 13 12 | 1 час 12 минут дня |
| 21 33 | 9 часов 33 минуты вечера |
| 00 00 | полночь |
| 03 01 | 3 часа 1 минута ночи |
| 24 03 | Введены недопустимые данные. |
| 2 3.5 | Ошибка: введите два целых числа. |

## Функции

| Функция | Назначение |
|---|---|
| `HasValidLineEnding()` | Проверяет остаток строки после двух чисел; допускает только пробельные символы |
| `PrintHours(int hours)` | Выводит число часов и форму «час», «часа» или «часов» |
| `PrintMinutes(int minutes)` | Выводит число минут и форму «минута», «минуты» или «минут» |
| `PrintDayPeriod(int hours)` | Выводит название части суток по исходному часу |
| `main()` | Проверяет ввод, обрабатывает особые моменты, переводит часы в 12-часовую форму и вызывает функции вывода |

## Переменные

| Переменная | Тип | Назначение |
|---|---|---|
| `hours` | `int` | Исходный час, 0–23 |
| `minutes` | `int` | Исходные минуты, 0–59 |
| `displayHours` | `int` | Час для вывода, 1–12 |
| `nextSymbol` | `int` | Символ остатка строки или признак конца ввода |

Все числовые границы и коды завершения заданы именованными `const int` в анонимном пространстве имен. `std::string`, `auto`, указатели и массивы символов не используются. Входные числа и остаток строки проверяются до формирования результата. На ошибке код завершения 1, при корректном вводе 0.

## Последовательность для блок-схемы

Начало → ввод часов и минут → проверка синтаксиса и остатка строки → проверка диапазонов → проверка 12:00 → проверка 00:00 → перевод часа в диапазон 1–12 → вывод часа с окончанием → минуты равны нулю? → при ненулевых минутах вывести минуты с окончанием → вывести часть суток → при нулевых минутах добавить «ровно» → конец.

Из каждой неуспешной проверки ввода перейти к соответствующему сообщению об ошибке и завершению с кодом 1; из проверок полудня и полуночи — вывести специальное название и завершиться с кодом 0. Для выбора окончаний сначала проверить 11–14, затем последнюю цифру 1, затем последние цифры 2–4, иначе использовать множественное число.
