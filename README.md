## Структура и методы

- main.cpp — только передача управления Roots::RunApplication.
- Application.hpp / Application.cpp — отдельные функции меню, цикла, ввода и вывода.
- Roots.hpp / Roots.cpp — namespace Roots, enum class Method : int, Status, структура Result и независимые от ввода/вывода вычисления.

Решается f(x) = x − a·cos(x) = 0. Пользователь задаёт коэффициент a, погрешность eps и x0 либо отрезок [left,right].

1. Простые итерации: x_(k+1) = a·cos(x_k).
2. Половинное деление: выбирается половина отрезка со сменой знака функции, знаки сравниваются без умножения. Используется std::midpoint.
3. Ньютон: x_(k+1) = x_k − (x_k−a·cos(x_k))/(1+a·sin(x_k)).

Для итераций и Ньютона требуются |x_(k+1)−x_k| ≤ eps и |f(x_(k+1))| ≤ eps. Для бисекции — полуширина отрезка ≤ eps и невязка ≤ eps (либо точное равенство f(mid)=0). Корень на границе и начальная точка с невязкой ≤ eps принимаются сразу с N=0.

Не более 99999 итераций; отдельные статусы для отсутствия сходимости, близкой к нулю производной, переполнения, неверного отрезка и достижения предела double. При неуспехе приближение не выдаётся за корень.

Ограничения ввода: |a|, |x0|, |left|, |right| ≤ 1e6; 1e−12 ≤ eps ≤ 1e−2. Значения должны быть конечными; дробный пункт меню и лишние символы отклоняются. После результата или ошибки можно повторить вычисление. EOF завершает работу.

## Объяснение результатов

При a=1 единственный корень x ≈ 0.739085133215. На [0,1] функция непрерывна, знаки на концах различаются. Бисекция сходится за счёт уменьшения отрезка вдвое; простой итерации помогает |−sin(x*)| ≈ 0.674 < 1. Метод Ньютона около простого корня обычно сходится быстрее. При a=10 простая итерация с x0=0.5 не сходится за лимит. Бисекция на [0,2] и Ньютон с x0=0.5 находят x ≈ 1.427551778765. Успех Ньютона зависит от начальной точки, поэтому несходимость этого метода при a=10 не является обязательной.

241 автоматическая проверка: сравнение с независимой бисекцией для коэффициентов −1..1 и eps от 1e−6 до 1e−12, коэффициент 10, несходимость, производная, интервалы, корни на границах, повтор и восстановление ввода.
